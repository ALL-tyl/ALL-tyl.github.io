Markdown 语法教程

Markdown 是一种轻量级标记语言，由 John Gruber 于 2004 年创建。它允许人们使用易读易写的纯文本格式编写文档，然后转换成有效的 HTML 文档。本教程将全面介绍 Markdown 的各种语法。

4. 列表

无序列表

使用 -、* 或 + 作为列表标记。

效果：

  • 项目一
  • 项目二
    • 子项目一
    • 子项目二
  • 项目三

有序列表

使用数字加 . 表示。

效果：

  1. 第一项
  2. 第二项
    1. 子项一
    2. 子项二
  3. 第三项

提示：有序列表的数字不必严格按顺序书写，渲染器会自动编号。

列表嵌套

子列表需要缩进（通常 2 或 4 个空格）。

10. 表格

使用 | 分隔列，使用 - 分隔表头与内容。: 用于控制对齐方式。

基本语法

效果：

姓名 年龄 城市
张三 25 北京
李四 30 上海

对齐方式

效果：

左对齐 居中对齐 右对齐
内容1 内容2 内容3
内容4 内容5 内容6

表格中的格式化

表格单元格内可以使用加粗、斜体、代码等语法，但换行需使用 <br>。

11. 任务列表

使用 - [ ] 表示未完成任务，- [x] 表示已完成任务。

效果：

  • 完成任务一
  • 完成任务二
  • 完成任务三
    • 子任务一
    • 子任务二

注意：任务列表在 GitHub、Typora 等平台支持良好，并非所有 Markdown 渲染器都支持。

16. 数学公式

部分渲染器（如 Typora、GitHub、Obsidian）支持 LaTeX 数学公式。

行内公式

使用 $...$ 包裹。

效果：质能方程：$E = mc^2$

块级公式

使用 $$...$$ 包裹。

效果：

$$
\int_{a}^{b} f(x) , dx = F(b) - F(a)
$$

17. 目录生成

部分平台（如 Typora、GitHub）支持使用 [TOC] 自动生成目录。

说明：不同平台对目录生成的支持不同，GitHub 不直接支持 [TOC]，但会为标题自动生成锚点。

附：Markdown 规范与扩展

  • CommonMark：标准化的 Markdown 规范
  • **GFM (GitHub Flavored Markdown)**：GitHub 扩展，支持表格、任务列表、删除线等
  • Markdown Extra：支持脚注、定义列表、表格等扩展

总结

Markdown 语法简洁易学，核心语法包括：

  • 标题：#
  • 强调：*、**、***
  • 列表：-、1.
  • 链接：[文字](地址)
  • 图片：![替代](地址)
  • 引用：>
  • 代码：`、 ``
  • 表格：|
  • 分隔线：---
